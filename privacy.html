Политика конфиденциальности приложения "Мой Мастер"

Дата вступления в силу: 16.08.2026

1. Общие положения

Настоящая Политика конфиденциальности описывает, как приложение "Мой Мастер" (далее — "Приложение") собирает, использует и защищает информацию, предоставленную пользователями.

2. Какие данные мы собираем

Для работы Приложения мы используем только те данные, которые предоставляет платформа ВКонтакте через VK Bridge:

  • VK ID пользователя — для идентификации в системе.
  • Имя и фамилия — для отображения в профиле и отзывах.

Мы не запрашиваем доступ к личным сообщениям, друзьям, фотографиям или другим приватным данным пользователя.

3. Как мы используем данные

  • Для создания и публикации заявок на услуги.
  • Для формирования рейтинга и отзывов о мастерах.
  • Для работы партнерской программы и начисления выплат.

4. Передача данных третьим лицам

Мы не передаем ваши личные данные третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

5. Хранение данных

Данные пользователей хранятся на защищенных серверах Supabase и используются исключительно для функционирования Приложения.

6. Контакты

По всем вопросам, связанным с политикой конфиденциальности, вы можете написать администрации сообщества "Мой мастер — поиск исполнителей" ВКонтакте.
